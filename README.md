# 💬 WhatsApp Chat Sentiment Analyzer 

This project is a sentiment analysis tool that processes WhatsApp chat exports to determine the **emotional tone** of messages using Natural Language Processing (NLP). It helps gain insights into **user emotions, opinions, and behavior** from conversation logs.

## 🔍 Use Cases

- 📢 Analyzing **customer feedback** from WhatsApp chats
- 📊 Monitoring **brand reputation** and customer sentiment
- 🧠 Gaining emotional insights from personal or group conversations

## 🧰 Technologies Used

- 🐍 Python (Pandas, Steamlit, Transformers)
- 📄 WhatsApp Chat Parser (txt file)
- 📈 Matplotlib / Seaborn for data visualization
- 🧪 Jupyter Notebook for experimentation and plotting

## 🚀 Features

- ✅ Import and clean raw `.txt` WhatsApp chat export
- ✅ Detect and tag each message’s sentiment: Positive, Negative, or Neutral
- ✅ Visualize sentiment over time using line plots
- ✅ Word Cloud generation for each sentiment
- ✅ Identify most active users and time-based message patterns
